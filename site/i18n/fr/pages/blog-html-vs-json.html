HTML ou JSON pour tes données Instagram ?

Quand tu demandes tes données, Instagram te demande un format. Choisis le mauvais et beaucoup d’outils ne pourront pas le lire. Voici la différence.

Les deux formats

  • HTML : des pages web que tu ouvres et lis dans un navigateur. Faciles à parcourir, difficiles à analyser pour un logiciel.
  • JSON : des fichiers de données structurés comme followers_1.json. Pas jolis à lire, mais exacts : chaque follower, date et message dans un format que les outils traitent.

Lequel choisir

Choisis JSON si tu veux analyser quoi que ce soit : unfollows, mutuels, messages ou temps d’écran. Choisis HTML seulement pour parcourir tes données toi-même. Le contenu est le même ; seul l’emballage change.

Tu as déjà téléchargé en HTML ?

Inutile de redemander : Unwrapped lit les exports HTML et JSON. D’autres outils n’acceptent souvent que le JSON ; redemande alors avec Format : JSON et Période : Depuis le début. Voir comment télécharger tes données Instagram.

FAQ

Le HTML contient-il moins de données que le JSON ?

Non : la même information, emballée autrement. Le JSON est juste plus facile à lire précisément pour les outils.

De quel format ont besoin les outils d’unfollowers ?

La plupart demandent du JSON. Unwrapped accepte les deux.

Puis-je changer de format après le téléchargement ?

Non, tu demandes un nouveau téléchargement dans l’autre format. Une demande limitée aux followers est souvent prête en quelques minutes.
