Comment ça marche

Trois étapes, une minute.

  1. Ouvrez Telegram DesktopSur ordinateur : ouvrez la discussion → ⋮ → Exporter l’historique. Pour tout : Paramètres → Avancé → Exporter les données Telegram.
  2. Choisissez JSONDécochez photos et vidéos et choisissez le format JSON lisible par machine. Vous obtenez un dossier avec result.json.
  3. Déposez-le iciLe fichier est lu dans votre navigateur. Rien ne quitte votre appareil — pas même les noms.
FAQ

Statistiques Telegram, expliquées.

Est-ce sûr d’analyser ma discussion ici ?

Oui. Le fichier est ouvert par votre navigateur et jamais envoyé. Vous pouvez même passer en mode avion une fois la page chargée.

Ça marche avec les groupes ?

Oui. Chaque participant a ses statistiques ; Pro affiche une fiche détaillée par personne.

L’autre personne le sait-elle ?

Non. Exporter une discussion n’envoie aucune notification, et l’analyse se fait uniquement sur votre appareil.

C’est gratuit ?

L’aperçu est gratuit. Pro ajoute les classements complets et une fiche par personne.
