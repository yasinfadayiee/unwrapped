¿HTML o JSON para tus datos de Instagram?

Cuando pides tus datos, Instagram pregunta por el formato. Si eliges el equivocado, muchas herramientas no podrán leerlo. Esta es la diferencia.

Los dos formatos

  • HTML: páginas web que abres y lees en el navegador. Fáciles de hojear, difíciles de analizar para un programa.
  • JSON: archivos de datos estructurados como followers_1.json. No son bonitos de leer, pero son exactos: cada seguidor, fecha y mensaje en un formato que las herramientas pueden procesar.

Cuál elegir

Elige JSON si quieres analizar algo: unfollowers, mutuos, mensajes o tiempo de uso. Elige HTML solo si quieres hojear tus datos tú mismo. El contenido es el mismo; solo cambia el envoltorio.

FAQ

¿HTML contiene menos datos que JSON?

No: la misma información, empaquetada distinto. JSON simplemente es más fácil de leer con precisión para las herramientas.

¿Qué formato necesitan las herramientas de unfollowers?

La mayoría necesita JSON. Unwrapped acepta ambos.

¿Puedo cambiar el formato después de descargar?

No, pides una nueva descarga con el otro formato. Una petición solo de seguidores suele estar lista en minutos.
