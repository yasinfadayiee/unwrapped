¿Quién escribe primero?

Exporta un chat y mira quién empieza la conversación, quién responde más rápido y quién escribe más.

La respuesta corta

WhatsApp no lo muestra, pero cada chat exportado tiene la hora de cada mensaje. Con eso puedes contar quién envió el primer mensaje después de cada pausa.

Revisa un chat

  1. Abre el chat → nombre del contacto → Exportar chat → Sin archivos. Mira cómo exportar un chat de WhatsApp.
  2. Arrastra el archivo al analizador de chats de WhatsApp.
  3. Abre Quién se esfuerza más para ver quién empieza las conversaciones, los tiempos de respuesta y cuántos mensajes envía cada uno.

El chat se lee en tu dispositivo. No se sube nada.

Léelo con cariño

Hay gente que simplemente tiene más tiempo libre o prefiere llamar. Mira la tendencia de varios meses y no de una semana, y úsalo para empezar una conversación, no para ganar una discusión.

FAQ

¿La otra persona sabe que exporté el chat?

No. Exportar un chat no envía ningún aviso.

¿Funciona con grupos?

Sí. Los chats de grupo se exportan y analizan igual.

¿Funciona en iPhone y Android?

Sí. Se admiten los dos formatos de exportación.
