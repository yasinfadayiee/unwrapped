Wer folgt dir auf X nicht zurück?

X hat die meisten Follower-Apps lahmgelegt, als es seine kostenlose API schloss. Dein eigenes X-Archiv enthält beide Listen weiterhin — und mehr brauchst du nicht.

Warum die meisten X-Unfollower-Apps nicht mehr funktionieren

Follower-Apps lasen deine Listen über die API von X. Seit der API-Zugang kostenpflichtig und eingeschränkt ist, haben viele aufgegeben oder verlangen vollen Zugriff auf deinen Account. Dein Datenarchiv ist der verlässliche Weg, der bleibt.

In wenigen Minuten prüfen

  1. Auf X: Einstellungen und Datenschutz → Dein Account → Ein Archiv deiner Daten herunterladen. X bereitet es in etwa einem Tag vor.
  2. Leg die Archiv-ZIP bei Unwrapped ab. Sie wird in deinem Browser gelesen — nichts wird hochgeladen.
  3. Öffne Folgen nicht zurück. Das Archiv listet Accounts nach ihrer ID, daher hat jede Zeile einen Button, der das Profil auf X öffnet.

Was dein X-Archiv sonst noch zeigt

  • Deine alten Tweets, durchsuchbar, mit einem Aufräum-Check für riskante Posts.
  • Deine besten Posts und deine Posting-Gewohnheiten.
  • Die Interessen und Werbetreibenden, die X dir zugeordnet hat, und verbundene Apps.

FAQ

Kann ich sehen, wer mir auf X entfolgt ist?

Ja, indem du zwei Archive von verschiedenen Daten vergleichst. Unwrapped speichert jedes als privaten Snapshot und vergleicht sie.

Warum zeigt das Archiv IDs statt Nutzernamen?

So speichert X deine Follower-Listen. Jede ID öffnet das richtige Profil, auch wenn die Person ihren @Namen geändert hat.

Ist es kostenlos?

Ja, die Analyse ist kostenlos. Plus zeigt die kompletten Listen und speichert deinen Verlauf.
