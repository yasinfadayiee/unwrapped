Instagram verilerin için HTML mi JSON mu?

Verilerini istediğinde Instagram bir biçim sorar. Yanlışını seçersen birçok araç onu okuyamaz. Farkı burada.

İki biçim

  • HTML: tarayıcıda açıp okuyabildiğin web sayfaları. Göz gezdirmesi kolay, yazılımla analiz etmesi zor.
  • JSON: followers_1.json gibi yapılandırılmış veri dosyaları. Okuması hoş değil ama kesindir: her takipçi, tarih ve mesaj araçların işleyebileceği biçimde.

Hangisini seçmeli

Bir şeyi analiz etmek istiyorsan (takipten çıkanlar, karşılıklılar, mesajlar veya ekran süresi) JSON seç. Verilerine yalnızca kendin göz atmak istiyorsan HTML seç. İçerik aynıdır; yalnızca paketleme farklıdır.

Zaten HTML mi indirdin?

Yeniden istemene gerek yok: Unwrapped hem HTML hem JSON dışa aktarmalarını okur. Diğer araçlar çoğu zaman yalnızca JSON kabul eder; o durumda Biçim: JSON ve Tarih aralığı: Tüm zamanlar ile yeniden iste. Instagram verilerini nasıl indireceğine bak.

FAQ

HTML, JSON’dan daha az veri mi içerir?

Hayır, aynı bilgi farklı paketlenmiştir. JSON yalnızca araçların doğru okuması için daha kolaydır.

Takipten çıkan araçları hangi biçime ihtiyaç duyar?

Çoğu JSON ister. Unwrapped ikisini de kabul eder.

İndirdikten sonra biçimi değiştirebilir miyim?

Hayır, diğer biçimle yeni bir indirme istersin. Yalnızca takipçi isteği çoğu zaman dakikalar içinde hazır olur.
