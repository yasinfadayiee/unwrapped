Comment télécharger tes données Threads

Ton téléchargement Threads contient tes listes d’abonnés et d’abonnements. Demande le fichier dans l’Espace Comptes, puis vérifie qui ne te suit pas en retour sans donner ton mot de passe à une application.

La réponse courte

  1. Ouvre Espace Comptes → Vos informations et autorisations → Télécharger vos informations.
  2. Sélectionne ton profil Threads et demande Followers et abonnements.
  3. Choisis JSON et depuis le début, puis crée les fichiers.
  4. Une fois le téléchargement prêt, enregistre le ZIP et dépose-le sur Unwrapped pour Threads.

Demander le téléchargement, pas à pas

  1. Si tu pars d’Instagram, va sur ton profil et touche ☰ → Espace Comptes.
  2. Ouvre Vos informations et autorisations → Télécharger vos informations → Télécharger ou transférer des informations.
  3. Sélectionne ton profil Threads pour cette demande.
  4. Choisis Certaines de vos informations et coche Followers et abonnements.
  5. Choisis Télécharger sur l’appareil. Règle Période : depuis le début, Format : JSON et Qualité des médias : faible.
  6. Touche Créer les fichiers. Quand tu reçois l’e-mail et la notification, télécharge le ZIP.

Sur ordinateur, suis aussi Espace Comptes → Vos informations et autorisations → Télécharger vos informations, puis sélectionne ton profil Threads.

JSON ou HTML ?

Le JSON est lisible par les machines et constitue le choix le plus fiable pour Unwrapped. Le HTML est fait pour être lu dans un navigateur. Choisis JSON pour analyser le fichier.

Combien de temps faut-il attendre ?

Les petites demandes sont souvent prêtes en quelques minutes ; les plus grosses peuvent prendre des heures et, dans de rares cas, quelques jours. Tu reçois un e-mail et une notification. Le lien expire au bout de quelques jours : télécharge donc le fichier rapidement.

Ce que contient le ZIP

  • Abonnés : les comptes qui suivent ton profil Threads.
  • Abonnements : les comptes que tu suis sur Threads.

Ce sont les listes nécessaires pour comparer les abonnés. Garde le ZIP tel quel : inutile de le décompresser avant de le déposer sur Unwrapped pour Threads.

Ce qu’Unwrapped te montre

  • Ne te suivent pas en retour : les comptes présents dans tes abonnements, mais absents de tes abonnés.
  • Fans : les personnes qui te suivent sans que tu les suives en retour.
  • Désabonnements : les comptes qui disparaissent de tes abonnés quand tu compares un export plus récent à l’instantané précédent.

Le premier export devient un instantané privé dans ton navigateur. Ajoute ensuite un export plus récent dans le même navigateur, sur le même appareil, pour les comparer. Un seul téléchargement ne permet pas de retrouver les désabonnements antérieurs au premier instantané.

Garde le fichier privé

Tes listes d’abonnés contiennent les noms de compte d’autres personnes. Unwrapped lit le ZIP sur ton appareil, sans rien envoyer. Il ne demande jamais ton mot de passe Instagram ou Threads. Supprime les copies supplémentaires de l’export quand tu n’en as plus besoin.

Questions fréquentes

Où demander mes données Threads ?

Dans l’Espace Comptes, ouvre Vos informations et autorisations → Télécharger vos informations, puis sélectionne ton profil Threads. Demande Followers et abonnements pour cette vérification.

Faut-il choisir JSON ou HTML ?

Choisis JSON pour l’analyse dans Unwrapped. Ce format est lisible par les machines ; le HTML est conçu pour être lu dans un navigateur.

Combien de temps prend le téléchargement ?

Les petites demandes sont souvent prêtes en quelques minutes. Les plus grosses peuvent prendre des heures et, dans de rares cas, quelques jours. Attends l’e-mail et la notification, puis télécharge le fichier avant l’expiration du lien.

Un seul export montre-t-il qui s’est désabonné ?

Un export permet de comparer tes abonnés et abonnements actuels. Pour repérer les désabonnements, compare un téléchargement plus récent à ton instantané précédent. Les désabonnements antérieurs à cet instantané ne peuvent pas être reconstitués.

Dois-je partager mon mot de passe Threads ou envoyer le fichier ?

Non. Unwrapped lit le ZIP téléchargé dans ton navigateur, sur ton appareil. Il ne demande pas ton mot de passe et n’envoie pas l’export.
