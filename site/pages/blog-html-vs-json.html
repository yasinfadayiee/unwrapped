HTML or JSON for your Instagram data?

When you request your data, Instagram asks for a format. Pick the wrong one and many tools can’t read it. Here’s the difference.

The two formats

  • HTML — web pages you can open and read in a browser. Easy to skim, hard for software to analyze.
  • JSON — structured data files such as followers_1.json. Not pretty to read, but exact: every follower, date and message in a format tools can process.

Which one to choose

Choose JSON if you want to analyze anything — unfollowers, mutuals, messages or screen time. Choose HTML only if you just want to browse your data yourself. The content is the same; only the packaging differs.

FAQ

Does HTML contain less data than JSON?

No — the same information, packaged differently. JSON is just easier for tools to read accurately.

Which format do unfollower tools need?

Most need JSON. Unwrapped accepts both.

Can I change the format after downloading?

No, you request a new download with the other format. A followers-only request is often ready in minutes.
