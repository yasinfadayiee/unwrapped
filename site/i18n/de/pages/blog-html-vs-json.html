HTML oder JSON für deine Instagram-Daten?

Wenn du deine Daten anforderst, fragt Instagram nach dem Format. Wählst du das falsche, können viele Tools sie nicht lesen. Hier ist der Unterschied.

Die zwei Formate

  • HTML — Webseiten, die du im Browser öffnen und lesen kannst. Leicht zu überfliegen, schwer für Software auszuwerten.
  • JSON — strukturierte Datendateien wie followers_1.json. Nicht schön zu lesen, aber exakt: jeder Follower, jedes Datum und jede Nachricht in einem Format, das Tools verarbeiten können.

Welches du wählen solltest

Wähle JSON, wenn du irgendetwas auswerten willst — Unfollower, gegenseitige Follower, Nachrichten oder Bildschirmzeit. Wähle HTML nur, wenn du deine Daten selbst durchblättern willst. Der Inhalt ist gleich; nur die Verpackung unterscheidet sich.

Schon als HTML heruntergeladen?

Kein Grund, neu anzufordern: Unwrapped liest HTML- und JSON-Exporte. Andere Tools akzeptieren oft nur JSON — dann fordere erneut mit Format: JSON und Zeitraum: Gesamter Zeitraum an. Siehe so lädst du deine Instagram-Daten herunter.

FAQ

Enthält HTML weniger Daten als JSON?

Nein — dieselben Informationen, anders verpackt. JSON ist für Tools nur leichter exakt zu lesen.

Welches Format brauchen Unfollower-Tools?

Die meisten brauchen JSON. Unwrapped akzeptiert beides.

Kann ich das Format nach dem Download ändern?

Nein, du forderst einen neuen Download im anderen Format an. Eine reine Follower-Anfrage ist oft in Minuten fertig.
