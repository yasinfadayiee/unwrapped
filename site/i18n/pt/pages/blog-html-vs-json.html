HTML ou JSON para seus dados do Instagram?

Quando você pede seus dados, o Instagram pergunta o formato. Escolha o errado e muitas ferramentas não conseguem ler. Veja a diferença.

Os dois formatos

  • HTML: páginas web que você abre e lê no navegador. Fáceis de folhear, difíceis de analisar por software.
  • JSON: arquivos de dados estruturados, como followers_1.json. Não são bonitos de ler, mas são exatos: cada seguidor, data e mensagem num formato que ferramentas processam.

Qual escolher

Escolha JSON se quiser analisar algo: unfollowers, mútuos, mensagens ou tempo de tela. Escolha HTML só se quiser folhear seus dados você mesmo. O conteúdo é o mesmo; só muda a embalagem.

Já baixou em HTML?

Não precisa pedir de novo: o Unwrapped lê exportações em HTML e JSON. Outras ferramentas costumam aceitar só JSON; aí peça de novo com Formato: JSON e Período: Desde o início. Veja como baixar seus dados do Instagram.

FAQ

HTML tem menos dados que JSON?

Não: a mesma informação, empacotada de outro jeito. JSON só é mais fácil de ler com precisão pelas ferramentas.

Qual formato as ferramentas de unfollowers precisam?

A maioria precisa de JSON. O Unwrapped aceita os dois.

Dá para mudar o formato depois de baixar?

Não, você pede um novo download no outro formato. Um pedido só de seguidores costuma ficar pronto em minutos.
