No followers file in your download?

You waited for your Instagram data, opened the ZIP… and there’s no followers list. It’s almost always one of five things.

Where the file should be

In a JSON download, your lists live in connections/followers_and_following/: followers_1.json (followers; large accounts get followers_2.json and more) and following.json. Older downloads put the same files one folder higher. See every file explained.

The five usual causes

  1. You chose HTML instead of JSON. The HTML files contain the same people but many tools can’t read them. Unwrapped reads both — but if you’re using another tool, request JSON.
  2. “Followers and following” wasn’t selected. If you picked only messages or media, the lists aren’t included. Request again with Customize information → Followers and following.
  3. Your download came in several parts. Big downloads are split into multiple ZIPs; the lists may be in another part. Keep all parts and drop them together.
  4. You downloaded a different account. Accounts Center can hold several profiles — check which one you selected.
  5. The ZIP was unzipped on a phone. Some phone apps flatten or drop folders. Drop the original ZIP instead of the unzipped folder.

The fastest working request

  1. Accounts Center → Your information and permissions → Export your information.
  2. Choose Customize information → Followers and following.
  3. Format JSON, date range All time.
  4. Drop the ZIP on Unwrapped — if something is still missing, it tells you exactly what and why.

FAQ

What is followers_1.json?

It’s the file in your Instagram data download that lists every account following you, with the date each one followed.

Why is following.json missing?

Usually because “Followers and following” wasn’t selected, or it’s in another part of a multi-part download. Request again with that category in JSON.

How long does a new request take?

A followers-only request is often ready in minutes. See how long the download takes.
