À qui est-ce que j’écris le plus sur Instagram ?

Instagram ne classe pas les personnes avec qui tu échanges le plus de messages. Ton export contient les messages nécessaires pour compter tes conversations les plus actives.

Comment trouver tes chats les plus actifs

  1. Demande tes données Instagram, sélectionne Messages et choisis le format JSON.
  2. Ouvre le ZIP dans l’analyseur de DM Instagram.
  3. Va dans Activité → Tes meilleurs potes en DM pour voir les conversations classées par nombre de messages.

Ce que signifient les chiffres

La tuile Messages indique le total des messages et des conversations de ton export. Tes meilleurs potes en DM classe les conversations par nombre de messages et reprend leurs titres dans l’export. Les discussions de groupe peuvent aussi apparaître.

Envoyés vs reçus sépare les messages que tu as envoyés de ceux que tu as reçus. Le graphique horaire montre les heures les plus actives. Le Lecteur de messages te permet de lire les chats sur ton appareil. Le classement compte les messages sans analyser ni juger leur texte. Un nombre élevé ne prouve pas une amitié proche.

Gratuit et avec Plus

Les 3 premières conversations sont gratuites ; Plus affiche les 10 premières. Pour les délais de réponse et les messages sans réponse, consulte l’analyseur de DM : ces statistiques concernent uniquement les conversations à deux.

Tes chats restent sur ton appareil

Le ZIP est lu sur ton appareil. Rien n’est envoyé, personne n’est averti et aucune connexion à Instagram n’est nécessaire.

Questions fréquentes

Puis-je le voir sans outil ?

Instagram ne propose pas ce classement dans l’app. L’export contient tes messages, que tu peux compter toi-même.

L’autre personne est-elle avertie ?

Non. Lire ton export sur ton appareil n’envoie aucune notification.

Les discussions de groupe sont-elles incluses ?

Elles peuvent apparaître dans le classement par nombre de messages. Les délais de réponse et les statistiques de messages sans réponse concernent uniquement les conversations à deux.

Combien de conversations sont gratuites ?

Les 3 premières sont gratuites. Plus affiche les 10 premières.

Que dois-je télécharger ?

Sélectionne Messages et le format JSON dans ta demande de données Instagram. Ouvre le ZIP téléchargé dans l’analyseur.
