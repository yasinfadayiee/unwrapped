Demande tes données

  1. Dans l’app TikTok : profil → ☰ → Paramètres et confidentialité → Compte.
  2. Touche Télécharger tes données.
  3. Sur ordinateur ? Utilise la page web ci-dessous.
Ouvrir la page de TikTok

Choisis « Toutes les données » + JSON

  1. Choisis Toutes les données — ton historique de visionnage n’est inclus que là.
  2. Format de fichier JSON (TXT fonctionne aussi).
  3. Touche Demander les données.

Télécharge et dépose

TikTok peut mettre de quelques heures à quelques jours. Quand c’est prêt, ouvre l’onglet Télécharger les données, enregistre le ZIP et dépose-le ici.
