Fordere deine Daten an

  1. In der TikTok-App: Profil → ☰ → Einstellungen und Datenschutz → Konto.
  2. Tippe auf Deine Daten herunterladen.
  3. Am Computer? Nutze die Webseite unten.
TikToks Seite öffnen

Wähle „Alle Daten“ + JSON

  1. Wähle Alle Daten — nur dort ist dein Wiedergabeverlauf enthalten.
  2. Dateiformat JSON (TXT geht auch).
  3. Tippe auf Daten anfordern.

Herunterladen & ablegen

TikTok kann ein paar Stunden bis einige Tage brauchen. Wenn es fertig ist, öffne den Tab Daten herunterladen, speichere die ZIP und lege sie hier ab.
